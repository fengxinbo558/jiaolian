# FORM 手机端壳层与 PWA 适配设计

## 目标

在不改变桌面端信息架构、训练逻辑和本地数据模型的前提下，为 360–430px 宽度的 Android 与 iPhone 建立独立的移动端布局规则，并提供可安装的 PWA 独立窗口体验。

## 已确认问题

- 桌面双栏卡片在手机上被压缩，造成文字裁切和按钮竖排。
- 顶部品牌栏、页面内容、固定底栏和浏览器工具栏同时占用空间。
- 固定底栏没有为内容提供足够的底部留白。
- 训练页把次要控制和历史信息同时暴露在首屏，摄像画面与实时提示不够突出。
- 计划详情封面高度过大，主按钮和底栏互相覆盖。
- AI 输入区的状态文字挤压发送按钮。
- 恢复码未分组、未折叠，长字符串撑高首屏。
- 项目没有 Web App Manifest，因此无法作为完整 PWA 独立启动。

## 设计原则

1. 保留五个一级入口：首页、动作、AI 教练、计划、我的。
2. 手机端底栏始终单行显示图标和标签，触控目标不小于 48px。
3. 使用 `100dvh`、流式宽度和 `env(safe-area-inset-*)`，不为某一台设备写死尺寸。
4. 首屏只展示当前任务和一个主要操作，次要操作下沉。
5. 所有固定元素为正文预留空间，不允许遮挡可点击内容。
6. 桌面端样式只在现有断点外生效，避免整体重做。

## 页面方案

### 全局壳层

- 手机顶栏高 56px；仅保留 F/、当前状态和声音按钮。
- 底栏固定在安全区上方，高 64px；五等分，标签不换行。
- 正文底部留白 = 底栏高度 + 安全区 + 24px。
- 浏览器模式提示用户“添加到主屏幕”；独立模式隐藏提示。

### 动作库

- 单列紧凑卡片；缩略图占 40%，文字占 60%。
- 卡片只显示动作名、主要肌群、难度和是否可纠正。
- 辅助肌群与详细说明进入详情页。

### 计划与课程详情

- 封面高度控制在 42–48dvh，避免长图占满首屏。
- 课程数据紧跟封面，以三列紧凑统计展示。
- “开始训练”作为底部浮动主按钮，位于应用底栏上方。

### 实时训练

- 运行时隐藏一级导航，摄像画面使用动态视口高度。
- 当前动作、次数、纠正和示范缩略图覆盖在画面内。
- 首层仅保留暂停与结束；保存进度放到暂停状态中。
- 未开始时保留设置和完整按钮，避免功能消失。

### AI 教练

- 对话区域使用剩余动态高度滚动。
- 输入框固定在底栏上方；状态信息单独一行，不挤压发送按钮。
- 发送按钮固定尺寸并禁止换行。

### 邀请与恢复

- 验证卡片在小屏上改为底部面板式布局。
- 恢复码默认显示缩略片段，支持复制与展开。
- “进入 FORM”始终在首屏可触达。

## PWA

- 增加 manifest、192/512 图标和 `display: standalone`。
- 增加 service worker，缓存应用壳层和关键静态资源。
- 在浏览器模式提供安装入口，在 standalone 模式隐藏。
- 说明：普通浏览器工具栏不能由页面强制隐藏；安装后独立启动可移除常规浏览器导航 UI。

## 验收标准

- 360、375、390、412、430px 均无横向滚动。
- 文字不出现非设计性的竖排或单字换行。
- 固定底栏、浮动按钮、iPhone Home 指示条互不遮挡。
- Android Chrome 与 iPhone Safari 均可完成导航、输入、训练和恢复码流程。
- 设备横屏时训练画面和主要控制仍可用。
- 桌面端核心布局和数据逻辑不回归。
