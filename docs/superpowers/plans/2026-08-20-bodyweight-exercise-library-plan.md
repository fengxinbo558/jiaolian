# 徒手动作库实施计划

1. 完整保存 `exercises-dataset`，建立 17 个动作的本地审核清单，并复制通过审核的 180×180 素材到运行目录。
2. 扩展动作资料结构：动作分类、计量方式、主要肌群、辅助肌群、发力提示、拍摄要求、媒体和上线状态。
3. 增加动作库界面：分类筛选、17 张动作卡、真人素材、肌群信息和“可训练/验证中”状态。
4. 建立第一批分析器：反向弓步、提踵、高抬腿、标准俯卧撑、平板支撑。
5. 为第一批动作接入实时语音、单次评价、有效时长和总结。
6. 为第一批动作增加标准、错误、遮挡、速度、帧率和恢复回归测试。
7. 完成桌面与手机真实页面验收；未完成动作保持禁用，不伪装成可训练。
8. 第二批和第三批沿用同一质量门槛逐个开放。
