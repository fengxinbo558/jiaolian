# 高级相机优先训练体验实施计划

**规格：** `docs/superpowers/specs/2026-08-21-premium-camera-first-training-ui-design.md`

## 实施阶段

1. 固化已确认的横版、竖版品牌图，并建立视觉 token。
2. 重组 `index.html`：训练首页、动作库、计划、记录、设置、沉浸训练和总结成为明确视图。
3. 保留现有 DOM id 和摄像头/分析器接口，删除硬编码的双动作选择器，统一使用 17 动作 profile。
4. 新增纯模块：视图状态、热量计算、预设计划；扩展本地训练记录 schema，同时兼容旧记录。
5. 重构 `main.ts` 的渲染与导航，不改变 Worker、分析器和反馈调度核心逻辑。
6. 重写响应式样式：桌面横版品牌图、手机竖版品牌图、训练中隐藏长期导航、视频完整入画、Coach Ribbon 单一反馈。
7. 添加热量、视图、存储兼容和浏览器烟雾测试。
8. 执行全量测试、类型检查、生产构建、桌面/手机截图与无障碍检查。

## 安全边界

- 不修改 17 个动作分析算法，除非新 UI 暴露出明确回归。
- 不上传或保存摄像头画面。
- 不使用未经核对的动作媒体。
- 未设置体重时不显示热量数值。
- 训练进行中切换页面必须先结束或明确确认。

## 验收命令

- `npm test`
- `npm run build`
- 浏览器验证 1440×900、768×1024、390×844。
