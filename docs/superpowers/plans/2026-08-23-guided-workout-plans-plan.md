# 引导式整套训练实施计划

1. 扩展计划配置类型并录入 8 套计划，增加总组数、目标文案和计划估算辅助函数。
2. 新建纯逻辑计划运行器，覆盖热身、准备、训练、休息、放松和完成状态；为推进、跳过休息、延长休息和休息分类编写单元测试。
3. 在计划页增加详情弹层，显示全部动作、组数、目标和休息时间。
4. 在训练页增加训练节拍带、热身/休息/放松覆盖层和立即开始、延长、暂停、结束操作。
5. 将计划运行器接入摄像头分析结果；达到次数或有效保持时间后自动结束当前组，保持摄像头并切换到下一组或下一动作。
6. 聚合每组训练结果，在整套结束时生成包含完成度和休息节奏的总结与记录。
7. 增加响应式样式、焦点管理、键盘与状态播报。
8. 运行类型检查、单元测试、生产构建和浏览器流程测试；检查桌面与手机宽度截图、控制台错误及原有单动作流程。
