# FORM 150 动作库与个性化计划实施计划

对应规格：`docs/superpowers/specs/2026-08-24-150-exercises-personalized-plans-design.md`

## 阶段 1：动作数据与审核基础设施

1. 增加 100 个稳定动作 ID，不降低现有类型约束。
2. 新建独立动作扩展数据模块，包含分类、模式、器械、难度、肌群、呼吸、错误、安全、建议训练量和媒体状态。
3. 新建媒体审核清单与实时能力分级，未审核素材不能显示为正式素材。
4. 将新模块小步接入现有 `EXERCISE_PROFILES` 和动作库筛选。
5. 添加数量、唯一性、字段完整性、媒体状态和实时能力映射测试。
6. 运行全量测试与构建。

## 阶段 2：统一人物与第一批关键帧

1. 固定唯一角色参考图和生成规范。
2. 第一批制作 25 个徒手与活动度动作，每个 3–5 个关键阶段。
3. 逐图检查人物、短裤、肌群、肢体、器械、画面裁切和动作名称。
4. 只有审核通过的关键帧才合成循环动图并写入媒体清单。
5. 检查桌面与手机动作卡片裁切和加载失败状态。

## 阶段 3：剩余三批动作与素材

1. 第二批 25 个哑铃动作，重点审核器械穿模和左右手一致性。
2. 第三批 15 个弹力带及 10 个哑铃动作，重点审核锚点和受力方向。
3. 第四批剩余 25 个瑜伽、核心和有氧动作。
4. 每批完成数据、素材、页面和构建验证，失败项保留明确状态并继续其他动作。

## 阶段 4：实时识别能力扩展

1. 用关键点可见性、动作阶段可分性和视角稳定性筛选 A 级动作。
2. 优先复用通用分析器：深蹲、弓步、俯卧撑、髋铰链、肩推、弯举、划船、静态保持、交替抬腿。
3. 每个开放动作添加正常、幅度不足、对齐或稳定、追踪丢失、快速连续动作测试。
4. 真实摄像头逐项复核；不可靠动作降为 B 级跟练指导。

## 阶段 5：12 套固定计划

1. 扩展计划 schema，增加强度、适用经验、器械、热身、冷身、动作间休息、频率、肌群覆盖和替代动作。
2. 实现轻、中、高各 4 套计划。
3. 让所有计划进入现有计划运行器，保持组间倒计时、提前开始、延长休息和换动作流程。
4. 添加完整运行、目标计数、休息分类和计划完成测试。

## 阶段 6：推荐、自定义生成与收藏

1. 新建确定性推荐器，复用身体指标、活动水平、训练记录和能力记录。
2. 增加目标、经验、时间、器械、冲击偏好和动作排除字段。
3. 输出首选、两个备选、理由、周安排和强度解释。
4. 新建本地自定义计划生成器和共用计划验证器。
5. 支持文字与现有语音输入，生成后可编辑、替换、收藏、置顶、复制、再次训练和删除。
6. 添加不同用户输入产生不同推荐、旧数据迁移、非法计划回退和存储测试。

## 阶段 7：未来模型接口

1. 定义 `PlanModelProvider`、请求和结构化输出类型。
2. 定义 `/api/plan/generate` 服务端契约，不在前端保存 API Key。
3. 模型草稿必须经过与本地生成器相同的验证器。
4. 未配置模型或调用失败时回退到本地规则生成器。

## 阶段 8：最终验收

1. 按规格逐项审计动作数量、分类、素材和实时能力。
2. 视觉检查所有正式动图，无穿模、畸形、多肢体、错动作和错肌群。
3. 验证 12 套固定计划、个性化推荐和自定义计划完整流程。
4. 运行全量测试、TypeScript 检查和正式构建。
5. 在桌面和手机宽度检查本地网页，读取控制台错误。
6. 输出完成清单、测试证据、B 级动作列表和模型 API 接入位置。
