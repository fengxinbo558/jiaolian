# 开合跳素材与语音一致性修正

**日期：** 2026-08-19  
**状态：** 用户已确认实施

## 问题

素材库编号 `3224` 的文字说明描述标准开合跳，但关联 GIF 实际展示的是分腿屈体跳。把该媒体作为标准动作会误导用户，也会让“张开、收回”的语音与画面冲突。

## 修正方案

- 撤下 `3224` 的图片和 GIF，只保留动作名称、说明和肌群元数据入口。
- 开合跳改用项目内人工核对的三阶段示范：并拢、手脚同时张开、同时收回。
- 示范节奏使用接近自然训练的短循环，不使用深蹲的慢速演示周期。
- 语音跟随实际阶段：开始动作说“张开”，到达最大幅度说“收回”；动作结束后只播短评价，新一轮开始立即中止旧评价。
- 开合跳的单次评价和整组总结使用“幅度、同步、手臂、双脚”等专属文案，不出现“深度、下蹲”等深蹲文案。

## 验收

1. 页面不再请求或展示 `3224-1g5bPpA.gif`。
2. 开合跳示范明确展示并拢、张开、收回，且自然节奏循环。
3. 0.5–0.6 秒完整动作中，事件顺序为“张开 → 收回 → 完成”，只计一次。
4. 新动作开始时，上一动作评价不能阻塞当前阶段语音。
5. 自动测试、类型检查、生产构建和桌面/手机页面检查全部通过。
