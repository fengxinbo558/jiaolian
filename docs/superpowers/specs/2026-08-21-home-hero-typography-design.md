# 首页首屏精简设计

## 目标

解决首页主标题过大、中文断行失控、信息堆叠和阅读压力问题，让用户第一眼看懂产品价值并愿意开始训练。

## 已确认方案

- 视觉锚点：沿用现有 `F/` 品牌标识，不新增来源不明的图片或装饰。
- 主标题：`练对，比练多更重要。`
- 主标题固定为两行：`练对，` / `比练多更重要。`
- 副标题：`实时看动作，及时纠正。`
- 主按钮：`开始训练`
- 次按钮：`动作库`
- 删除原长段落、两个信任标签和“浏览 52 个动作”等冗余信息。

## 排版规则

- 中文标题使用当前正文家族的粗体，控制最大字号和行宽，不依赖浏览器自动断行。
- `word-break: keep-all`，移动端通过字号缩放而不是拆成单字。
- `F/` 作为唯一强装饰，其余元素保持安静。
- 主按钮保留珊瑚色；副按钮使用低对比玻璃样式。
- 保留键盘焦点、44px 以上点击区域和减少动态效果支持。

## 验收

- 桌面与手机宽度均只出现两行完整标题。
- 首屏文字不超过一个品牌标签、一句主张和一句说明。
- 原开始训练与动作库事件绑定保持不变。
