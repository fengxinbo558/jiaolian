# macOS 程序坞快捷启动器设计

日期：2026-08-22

## 目标

在当前电脑上提供一个可固定在程序坞的“FORM 动作教练”入口。用户点击后无需运行命令，也无需让开发助手再次启动项目，即可打开当前调试版本。

本阶段只解决快捷启动，不把网页改造成正式原生应用，不改变现有健身功能。

## 安装位置

- 启动器安装为 `/Applications/FORM 动作教练.app`。
- 将该应用固定到当前用户的 macOS 程序坞。
- 项目仍保留在现有目录，后续修改代码后无需重新打包整个桌面应用。

## 点击后的行为

1. 检查 `http://localhost:5173/` 是否已经是当前 FORM 项目。
2. 如果已经运行，直接使用默认浏览器打开页面，不重复启动服务。
3. 如果没有运行，在后台从当前项目目录启动开发服务，不显示终端窗口。
4. 等待页面可访问后，再使用默认浏览器打开。
5. 启动器退出后，后台开发服务继续运行；再次点击仍直接打开页面。

## 组件边界

- 项目内保存一个可阅读、可修改的启动脚本，负责检查、启动、等待和打开页面。
- macOS `.app` 只负责调用该脚本，不复制业务代码，不维护第二份网页。
- 日志写入项目的本地运行日志目录，便于启动失败时排查。

## 异常处理

- Node/npm 不存在：显示“启动环境缺失”，并提示日志位置。
- 5173 端口被其他程序占用且不是 FORM：不打开错误页面，显示端口冲突。
- 服务在限定时间内未启动：显示失败提示和日志位置。
- 项目目录被移动：显示“找不到项目”，不静默失败。
- 重复点击：不启动第二个开发服务。

## 验收标准

1. “FORM 动作教练”出现在 `/Applications` 和程序坞。
2. 停止项目后点击程序坞图标，项目能在后台启动并打开页面。
3. 项目已经运行时再次点击，只打开页面，不产生重复服务。
4. 启动过程不弹出终端窗口。
5. 页面仍能使用摄像头、麦克风及现有本机数据。
6. 启动失败时有用户看得懂的提示，并保留可检查的日志。
