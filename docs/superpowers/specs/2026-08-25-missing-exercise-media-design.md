# 缺失动作素材补齐设计

日期：2026-08-25

## 范围

补齐动作库中 23 个 `pending` 动作的示范素材，不改动现有 77 个动作素材。每个动作交付一张三阶段关键帧图和一个由审核后关键帧制作的往返循环 GIF。

## 统一视觉

- 与批次 01 相同的成年男性人体解剖线稿模型、头身比例和短黑发。
- 无具体五官，穿不透明黑色运动短裤；不出现裸体感。
- 主要发力肌群使用珊瑚红，其他肌肉保持黑白灰线稿。
- 米白纯净背景，无文字、编号、Logo、水印和装饰。
- 三阶段从左到右排列，人物完整入画；器械连续、结构正确且不穿过身体。

## 审核标准

逐张核对动作名称、起始位、中间位、完成位、左右方向、关节角度、器械数量与位置、短裤遮挡、肢体数量、肌群标注和画面裁切。未通过的图片不得写入 `VERIFIED_MEDIA`。

## 接入

通过审核后将 PNG 和 GIF 保存到 `public/assets/exercise-catalog/generated-batch-02/`，更新动作媒体映射、自动测试和素材审核表。应用仍保持“素材审核”与“摄像头实时识别”两种状态独立。
