# FORM 后续页面黑白安全感 UI 改版设计

日期：2026-08-26

## 目标

保留 FORM 健身产品的全部功能与现有首页人物封面，将封面之外的界面统一改造成更克制、现代、具有数据安全产品秩序感的黑白中性视觉。参考 `securify` 的悬浮胶囊、深色玻璃面板、大字号排版和数据展示方式，但不复制品牌、文案或视频。

## 严格保留范围

`.hero-card` 整块保持原样，包括：

- 桌面与移动端人物封面图片；
- 图片比例、裁切与人物位置；
- 遮罩、`F/` 标记、标题、副标题；
- “开始训练”和“动作库”按钮；
- 封面内部现有颜色、间距、字体层级和布局。

改版不得替换、重绘、移动或重新着色上述内容。

## 允许改版范围

- 顶部品牌栏和主导航；
- 首页封面下方的本周数据与推荐计划；
- 动作库及动作卡片；
- 摄像头训练页、实时数据、语音教练和动作说明；
- 计划推荐、自定义计划、计划详情与休息流程；
- 训练记录；
- 身体状态、语音录入、公式指标、能力记录；
- 训练总结；
- 弹窗、表单、筛选器、空状态和提示信息。

## 视觉方向

### 色彩

- 页面底色：`#000000`；
- 主面板：`#0a0a0a`、`#171717`；
- 面板边线：白色 10%–16% 透明度；
- 主文字：`#ffffff`；
- 次级文字：白色 55%–72% 透明度；
- 主操作：白底黑字；
- 状态颜色仅在必须表达成功、警告或错误时保留，面积要小；
- 禁止使用紫色和靛蓝色。

首页人物封面内部原有暖色不受这套全局色板覆盖。

### 字体与层级

- 界面字体加载 `Readex Pro` 300、400、500、600、700，并为中文保留系统字体回退；
- 后续页面主标题使用紧凑字距和大字号，形成明确视觉入口；
- 数字数据比标签显著更大；
- 标签小写英文只用于现有品牌或必要数据标识，中文业务文案不强行改成英文；
- 正文保持正常可读行高，不模仿落地页的超大广告文案。

### 组件语言

- 顶部栏改为悬浮胶囊结构：左侧品牌胶囊、中间导航胶囊、右侧语音与状态操作；
- 移动端继续使用易点击的底部导航，但改成浮动深色胶囊；
- 卡片统一为低透明深灰面板、细边框和中等圆角；
- 筛选器、标签、按钮使用胶囊形；
- 表单字段改为深色输入面板，白色聚焦边框；
- 页面之间用留白、字号和细线组织，不用多余装饰色。

## 各页面改版

### 首页封面下方

本周数据改为三列大数字统计，推荐计划改为横向节奏更清楚的深色计划卡。人物封面不参与改版。

### 动作库

标题区采用大字号与“100”数据对位；筛选器为可横向滚动的胶囊；动作卡片突出示范图、动作名、主要肌群和识别状态，弱化重复说明。

### 训练页

摄像头画面成为主视觉，数据与反馈采用黑色悬浮面板。当前指导优先级最高；次数、合格率、热量和延迟次之；动作说明折叠区保持可访问。

### 计划页

推荐条件、AI 组合输入、固定计划分成三个清楚区块。计划卡突出强度、时长、组数与器械，主按钮统一白底黑字。

### 记录页

顶部以总次数、合格率、热量形成数据概览，历史记录使用简洁时间线/列表，空状态给出明确下一步。

### 身体页

身体指标作为数据仪表区，录入与趋势分栏；语音输入保留编辑和确认流程；公式说明与免责声明保持可见但降低视觉权重。

### 总结页

用事实数据决定标题和评价，不做无条件夸奖。主要问题、下一组建议和来源标识形成明确阅读顺序。

## 行为与技术边界

- 不改变动作识别、计数、语音、热量、计划、记录和身体公式逻辑；
- 保留所有现有 DOM `id`、表单字段、事件绑定和本地数据格式；
- 允许为布局增加包装类或语义结构，但不做无关重构；
- 只保留链接文字颜色和主按钮底色两类 hover 过渡；
- 支持键盘焦点、移动端安全区和 `prefers-reduced-motion`；
- 不引入新 UI 框架；在现有 TypeScript + CSS 架构中完成，降低后续需求变更成本。

## 验收标准

1. 首页人物封面逐像素构图没有被样式覆盖或替换。
2. 封面之外所有主要页面使用统一黑白中性 UI。
3. 桌面与移动端均无横向溢出、文字遮挡或按钮不可点击。
4. 所有原有功能测试通过，摄像头与语音权限流程不被改动。
5. 动作卡图片、计划、记录和身体数据正常渲染。
6. 页面无紫色或靛蓝色装饰。
7. 浏览器无新增控制台错误。

## 自检结果

- 无 `TBD`、`TODO` 或未决视觉项；
- “保留封面”明确限定为 `.hero-card`，封面下方允许改版；
- 视觉改版与功能逻辑边界不冲突；
- 范围可在一次实现中完成，但应按全局骨架、业务页面、响应式与回归验证分阶段进行。
