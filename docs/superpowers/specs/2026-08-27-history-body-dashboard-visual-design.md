# 记录页与身体页视觉改版说明

日期：2026-08-27  
状态：用户已确认；身体页改用 2026-08-28 浅色日间方案

## 目标

在不改变训练记录、身体计算、语音录入及本机存储功能的前提下，重做记录页和身体页的视觉层级与空状态，使页面在没有数据时依然完整、易懂、可操作，有数据后也能自然承载趋势和结果。

本次不调整首页封面、实时训练识别逻辑、训练计划逻辑或数据公式。

## 已确认方向

记录页继续采用“分层石墨灰仪表盘”。身体页根据用户 2026-08-28 提供并确认的参考图，改用“暖白日间健康档案”方向：暖白页面、白色卡片、深色文字和柔和青柠强调色。身体页必须适合白天在手机上使用，不再继承纯黑背景。

### 记录页视觉令牌

- 页面背景：`#0E1112`
- 主面板：`#141819`
- 卡片表面：`#1A1F20`
- 悬浮或重点卡片：`#202627`
- 主要文字：`#F4F5F0`
- 次要文字：`rgba(244,245,240,.64)`
- 弱提示：`rgba(244,245,240,.42)`
- 边框：`rgba(244,245,240,.10)`
- 强调色：`#C7DB68`
- 强调色浅底：`rgba(199,219,104,.12)`

### 身体页视觉令牌

- 页面背景：`#F5F3ED`
- 主卡片：`rgba(255,255,255,.78)`
- 内层卡片：`#FFFFFF`
- 主要文字：`#131814`
- 次要文字：`#68706A`
- 弱提示：`#858C87`
- 边框：`rgba(28,36,31,.10)`
- 强调色：`#D4EA69`
- 强调浅底：`rgba(212,234,105,.22)`

身体页的强调色只用于主要按钮、当前导航、指标图标和已完成状态。卡片使用细边框和低强度阴影，不能出现灰黑面板或高对比黑卡。

## 排版规则

- 页面主标题：桌面端 40–48px，移动端 28–34px，行高 1.05–1.12。
- 区块标题：桌面端 24–28px，移动端 20–24px。
- 卡片指标数字：30–38px；不得用巨型数字填满卡片。
- 正文：15–17px，行高不低于 1.5。
- 辅助信息：13–14px，不低于 12px。
- 标题最大宽度受控，不再横跨全屏形成海报式大字。

## 共用页面结构

两页使用相同的内容宽度、顶部留白和卡片圆角：

1. 紧凑页头：眉题、主标题、说明文字、右侧主操作。
2. 概览区：紧凑指标卡，不重复堆放无意义的 0 或破折号。
3. 内容区：有数据时显示结果和趋势；无数据时显示一个明确的引导模块。

卡片圆角统一为 18–22px，边框 1px。允许轻微阴影或明度变化，不使用虚线大框作为主要空状态。

## 记录页

### 页头

- 标题保留“训练记录”，缩小到标准页面标题。
- 说明保留“看见连续性、动作质量和消耗趋势”。
- “清空记录”仅在存在记录时正常显示；空记录时弱化或隐藏，避免提供无意义操作。

### 概览卡

使用三张紧凑卡片：训练次数、动作总量、估算消耗。每张卡包含小图标、标签、指标和一句状态说明。

无记录时不显示三个巨大的 0/—，统一显示“尚未开始”，并用辅助文字解释第一次训练后会自动统计。存在记录后再显示真实数值和单位。

### 空状态

删除现有大面积虚线框，替换为完整的首次训练引导卡：

- 简洁的训练/趋势图形，不使用真人占位图。
- 标题：“还没有训练记录”。
- 说明：“完成一次训练后，这里会显示动作次数、质量反馈和消耗趋势。”
- 主按钮：“开始第一次训练”。
- 隐私提示：“记录只保存在这台设备”。

点击主按钮进入当前已有的动作选择或实时训练入口，不新增训练流程。

### 有数据状态

沿用现有记录列表的数据内容，调整为结构明确的卡片列表；日期、训练名称、完成量、热量和动作质量按重要性排列。不得改变历史数据结构。

## 身体页

### 页头

- 眉题保留“身体状态中心 · 本机保存”。
- 主标题改为更紧凑的“身体状态”，说明文字承接“看清当前数据，再安排训练”。
- 语音录入和本机隐私提示保留原功能，视觉上与页头对齐。

### 身体参考面板

不再使用纯黑大面板和超大标题。面板改为暖白主卡：上方为简短状态摘要和健康体重参考，下方为四张两列指标卡。手机端仍优先保持两列；只有极窄屏才改为单列。

四张卡片统一使用白色表面、线性图标和青柠浅底图标容器：

- BMI：空状态“待录入”，操作提示“填写身高体重”。
- 基础代谢：空状态“待计算”，操作提示“补全年龄与公式参数”。
- 日常总消耗：空状态“待估算”，操作提示“设置活动水平”。
- 体脂参考：空状态“可选评估”，操作提示“补充腰围、颈围等数据”。

每张卡增加独立线性图标及状态标签。数据齐全后，指标数字替换状态文案；超出普通参考范围时使用文字标签与图标共同表达，不只依赖颜色。

### 数据录入与趋势区

保留现有表单、语音录入、趋势记录和训练能力模块。统一卡片表面和边框，不改变字段、校验、公式或保存方式。

## 响应式规则

- 桌面端概览卡为三列，身体指标为两列或四列，视可用宽度决定。
- 平板端保持两列。
- 手机端概览卡允许横向紧凑两列或单列；主要按钮宽度足够触控。
- 所有可点击目标最小 44×44px。
- 不允许横向溢出；标题和指标必须在小屏幕内正常换行。

## 状态与兼容

- 不改任何本机存储键、数据模型和计算函数。
- 空状态仅根据现有记录数量和资料完整度显示。
- JavaScript 不可用时，页面仍显示可理解的静态空状态文字。
- 图标使用统一 SVG 线性图标，不使用 emoji、火柴人或与指标无关的人物素材。

## 验收标准

1. 记录页不再出现纯黑叠纯黑；身体页在桌面和手机宽度下均使用暖白日间背景。
2. 截图中的四处超大标题均缩小到标准页面或区块标题尺寸。
3. 空数据时不再以大号 `0` 和 `—` 作为页面主体。
4. BMI 卡与其他指标卡保持一致，均为白色内层卡片与青柠浅底图标。
5. 空状态明确告诉用户缺少什么、下一步做什么。
6. 原有训练记录、身体计算、语音输入、表单和本机存储功能不受影响。
7. 桌面、平板和手机宽度下均无溢出，文字对比度和操作区域符合可访问性要求。

## 测试范围

- 无训练记录、有一条记录、多条记录三种状态。
- 身体资料全空、只填必填项、填入完整围度三种状态。
- 桌面与手机视口视觉检查。
- 现有自动化测试和生产构建全部通过。
