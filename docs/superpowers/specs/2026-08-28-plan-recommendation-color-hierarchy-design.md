# 训练计划个人推荐区配色层级设计

日期：2026-08-28

## 定版依据

采用用户确认的参考图：暖白页面底布、深橄榄炭灰推荐面板、较亮石墨灰输入框与计划卡片。该视觉层级统一应用于训练计划页的推荐卡、固定计划卡、自定义及已收藏计划卡和本周完成卡，不改变布局、文字、功能、数据、按钮位置或训练流程。

## 色彩层级

| 层级 | 色值 | 用途 |
| --- | --- | --- |
| 页面底布 | `#F4F2EC` | 计划页面最外层背景，沿用全站暖白底布 |
| 推荐面板 | `#151A17` | “今天更适合练什么”完整推荐区域 |
| 输入框 | `#252B27` | 目标、时间、器械三个选择框 |
| 计划卡片 | `#252B27` | 推荐结果中的计划卡片 |
| 芯片 | `#303630` | 动作名称标签 |
| 卡片边框 | `#3B443D` | 输入框和计划卡片的清晰边界 |
| 主文字 | `#F7F8F3` | 深色区域中的标题与关键文字 |
| 次文字 | `#ADB4AE` | 说明文字与字段标签 |
| 强调色 | `#CFE65C` | 时间、强度、组数和器械等少量关键数据 |

## 视觉规则

- 推荐面板与暖白页面背景之间使用明显明暗差和柔和阴影。
- 输入框和计划卡片必须比推荐面板亮一级，不能继续使用相同黑色。
- 输入框与卡片增加一像素边框，不能只依赖阴影区分。
- 计划卡片内部保持现有结构，圆形时长标记只增加细荧光绿描边。
- 白色主按钮保持现状，不改成大面积荧光绿。
- 荧光绿只用于关键数字和状态，避免整块铺色。
- 不增加渐变、人物、图片、图标或新装饰。

## 修改边界

### 会修改

- `.plan-personalizer` 的背景、边框和阴影。
- `.plan-preference-controls select` 的背景和边框。
- 推荐区域内部 `.plan-card`、标签、时长圆标和数据强调色。
- 推荐区域内说明文字的对比度。
- `.plan-builder`、自定义输入框和已收藏计划卡的层级。
- `.plan-page-grid .plan-card` 与 `.week-progress-card` 的配色，使其与确认的计划卡样式一致。

### 不会修改

- 训练计划页面之外的其他界面和首页动作图片卡。
- 卡片尺寸、栅格、留白和内容顺序。
- 文字内容、筛选字段和推荐规则。
- 按钮位置、点击行为和语音功能。
- 用户保存的数据。

## 响应式

- 桌面端保留三列推荐卡布局。
- 手机端保持现有单列布局，颜色层级与桌面端一致。
- 不改变现有断点和滚动行为。

## 验收标准

- 暖白页面、深色推荐面板和石墨卡片三层能够一眼区分。
- 卡片不再与推荐面板融为一体。
- 深色区域的正文与标签仍清晰可读。
- 首页暖白底布上的“今日推荐”标题使用深色文字，不能继续继承深色页面的白字样式。
- 页面不存在横向溢出。
- 计划筛选、推荐更新、查看并开始训练保持可用。
