# FORM 全站暖白主题统一设计

日期：2026-08-28

## 目标

以当前“身体状态”页面的最外层暖白背景为统一底布，把首页、动作库、计划、记录、动作训练、计划详情和训练总结的页面背景统一起来。此次只改页面底色以及直接落在底色上的文字颜色，不整体替换卡片、人物、课程封面、数据框和其他前景组件，也不修改功能、数据、动作识别、语音、摄像头和导航逻辑。

## 已确认方向

- 全站只使用一套暖白日间主题，不增加深色主题切换。
- 首页现有的人物封面与素材不更换。
- 只统一各页面最外层背景，不把所有前景组件改成浅色。
- 首页人物、动作图、课程封面、训练大卡、数据框、筛选框和现有交互组件保持原来的结构与视觉性格。
- 深色卡片可以继续保留，并作为暖白页面上的高对比内容层。
- 卡片不能使用与页面背景过近的颜色；浅色卡片必须通过纯白表面、边框和阴影与暖白底布分层。

## 颜色系统

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 页面底色 | `#F5F3ED` | 所有页面的最外层背景 |
| 浅色卡片 | `#FFFFFF` | 原本就是浅色的表单与数据卡，和暖白底布拉开差异 |
| 深色卡片 | `#0A0A0A` / `#111310` | 保留现有课程封面、训练卡和深色信息框 |
| 主文字 | `#131814` | 标题、主要数字、按钮文字 |
| 次文字 | `#68706A` | 说明、标签、时间和辅助信息 |
| 分隔线 | `rgba(28, 36, 31, 0.10)` | 卡片边框和分隔线 |
| 品牌强调 | `#D4EA69` | 选中导航、主操作、进度和状态 |
| 媒体暗底 | `#111310` | 摄像头、视频、图片缺省区域及原有深色组件 |

## 修改边界

### 本次会改

- `body` 和各一级/二级页面的最外层背景。
- 原本直接显示在黑色页面背景上的标题、说明文字、分隔线颜色，调整为适合暖白背景的深色版本。
- 必要的页面留白，使深色卡片能清楚悬浮在暖白底布上。
- 浅色卡片与暖白背景过近时，只补充边框或轻阴影，不重做卡片。

### 本次不改

- 卡片结构、尺寸、内容顺序和交互。
- 首页人物封面、动作示范图和课程真人图。
- 截图示例中的深色课程大卡、下方训练组数/强度/休息信息框。
- 现有按钮样式、图标、选中状态和卡片内部配色，除非它们在暖白背景上失去可读性。
- 功能、数据、识别、语音、摄像头和训练流程。

## 页面规则

### 首页

- 页面最外层使用暖白。
- 原人物封面保持不变，作为独立的大幅媒体卡片存在。
- 封面之外的分类、推荐计划和训练数据保留现有卡片配色。
- 保留封面内部的暗色遮罩，确保文字可读。

### 动作库

- 页面背景改成暖白，筛选栏和动作卡片保留现有配色。
- 原动作示范图保持原样；图片位于清晰的媒体框内。
- 只调整直接落在页面背景上的标题和说明文字；卡片内部文字跟随卡片原配色。
- 已选分类保持现有荧光绿状态。

### 训练计划与计划详情

- 页面最外层改成暖白；筛选表单、计划卡片和详情信息区保留现有深浅关系。
- 课程真人封面保留暗色摄影风格，但只占封面区域。
- 组数、强度、休息时间可以继续使用截图中的深色数据框，与暖白背景形成清楚层级。
- 按钮沿用现有样式。

### 训练记录

- 石墨灰页面背景改成暖白。
- 三张统计卡和训练记录条目保留现有组件颜色；如使用浅色卡片，则补充边框与阴影避免融入背景。

### 身体状态

- 作为基准页面，保持现有方向。
- 不重新设计该页面的功能或前景组件。

### 实时训练

- 页面外壳改成暖白，统计和指导卡片保留现有组件配色。
- 摄像头画面保持深色，因为它属于媒体内容，并需要保证骨骼线和提示信息的对比度。
- 标准示范图的位置和交互保持现状。
- 摄像头内部阶段条、骨骼提示和实时数字可以保留深色半透明浮层。

### 训练总结

- 页面背景改成暖白，主要总结卡保留现有状态配色。
- 成绩状态通过荧光绿、琥珀色和红色的小面积标签表达，不使用整屏深色区分结果。

## 顶栏与底部导航

- 顶栏和底部导航属于前景组件，本次不强制改成暖白；优先保留现有形式。
- 当前页面继续使用荧光绿选中状态。
- 如果导航与新的暖白页面背景对比不足，只增加清晰边框或阴影，不重做结构和颜色体系。
- 训练进行中可以隐藏底部导航，但不能切换整页主题。

## 字体、尺寸与交互

- 现有字体、字号、卡片尺寸、内容顺序和交互保持不变。
- 只把直接落在新暖白背景上的浅色文字改为深色，以保证可读性。
- 手机端和桌面端原有响应式行为保持不变。

## 验收范围

实施后需要逐页检查并截图：

1. 首页
2. 动作库
3. 训练计划
4. 训练记录
5. 身体状态
6. 实时训练
7. 计划详情
8. 训练总结

验收标准：页面之间不再出现整页黑、整页灰和整页白的突兀切换；最外层底布统一为暖白，现有深色卡片与媒体内容作为清晰的前景层保留，不能与背景融在一起。

## 不在本次范围

- 不更换首页人物封面。
- 不重新生成动作图。
- 不修改动作识别、计数、语音和训练计划算法。
- 不增加日夜模式。
- 不改动用户已有记录和本机数据结构。
